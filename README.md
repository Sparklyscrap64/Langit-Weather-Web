# 🌤️ Langit — Aplikasi Website Cuaca

Website cuaca modern yang menampilkan kondisi cuaca terkini, prakiraan per jam, dan prakiraan 7 hari, lengkap dengan **mode terang (light)** dan **mode gelap (dark)**.

🔗 **Demo langsung:** https://langit-cuaca-nusantara.vercel.app

---

## 🖼️ Tampilan

Aplikasi mendukung dua tema yang bisa diganti lewat tombol di pojok kanan atas.

| Light Mode | Dark Mode |
| :---: | :---: |
| ![Tampilan Light Mode](image/LightMode.png) | ![Tampilan Dark Mode](image/DarkMode.png) |

## ☁️ Informasi Cuaca

Halaman detail menampilkan suhu, kelembapan, kecepatan angin, indeks UV, serta prakiraan per jam dan 7 hari ke depan.

## ✨ Fitur

- 🔍 Pencarian kota dengan saran otomatis
- 📍 Deteksi lokasi pengguna
- 🌡️ Suhu saat ini, suhu terasa, serta suhu tertinggi dan terendah
- 💧 Detail cuaca: kelembapan, angin, tekanan udara, jarak pandang, indeks UV
- ⏱️ Prakiraan per jam (24 jam) dan 7 hari
- 🌓 Mode terang dan gelap
- 📱 Tampilan responsif untuk HP, tablet, dan desktop

## 🛠️ Teknologi

- HTML, CSS, JavaScript
- [Open-Meteo API](https://open-meteo.com/) untuk data cuaca
- [Chart.js](https://www.chartjs.org/) untuk grafik
- Vercel untuk hosting
